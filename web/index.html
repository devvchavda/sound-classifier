        What it can recognise

        Each sound gets its own score from 0 to 100%, independent of the others, so it can hear several at once (a dog barking while someone talks) or none at all. The scores are corrected to be honest: of all the times it says about 60%, the sound really was there about 60% of the time, checked on clips it never trained on. It still knows only these sounds; music, for example, is not one of them.
